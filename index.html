Cómo tener este Dashboard en tu móvil siempre

Opciones gratuitas, privadas y automáticas

Opción 1: Subirlo a Vercel o GitHub Pages (100% Gratis y Privado)

Puedes subir este único archivo index.html a un repositorio privado de GitHub o desplegarlo en Vercel / Netlify arrastrando el archivo. Tendrás un enlace https://micontabilidad.vercel.app accesible desde cualquier navegador y dispositivo.

/ Opción 2: "Añadir a la Pantalla de Inicio" (Icono de App)

Una vez abierto el enlace en Safari (iPhone) o Chrome (Android), pulsa en Compartir / Menú ⋮ y selecciona "Añadir a la pantalla de inicio". Se abrirá a pantalla completa como si fuese una app descargada del App Store, con carga ultra rápida y sin barras de navegador.

Opción 3: Sincronización con Google Sheets

Si quieres que los datos se actualicen cuando edites celdas, este mismo archivo HTML se puede conectar directamente mediante la API de Google Sheets para que lea tus gastos en tiempo real.
